## 모델 생성 방식 — B안으로 확정

| 단계 | 도구 | 설정 | 시간·VRAM (RTX 4060 Ti 8GB) |
|---|---|---|---|
| 형태 | Hunyuan3D-2mv (3면도 정면·왼쪽·후면) | octree 380, 면 10만 | 약 2분 · 5.7GB |
| 전신 텍스처 | Hunyuan3D-Paint v2.0 (full) | 2048, CPU offload | 약 2분 · 4.6GB |
| 머리 텍스처 (B안) | 같은 Paint, 머리만 | 3면도 얼굴 클로즈업 입력, 모델 꼭대기 17%를 머리로 | 약 1분 · 4.6GB |

- 머리만 따로 칠하는 이유: Paint는 512px 그림 6장으로 칠한다. 전신이면 얼굴에 쓰이는 픽셀이 적어 이목구비가 흐리다. 머리만 돌리면 같은 512px이 머리에만 쓰인다.
- 결과 GLB는 몸·머리 두 메시(각자 2048 텍스처), 한 명 약 7MB.
- 비교해 보고 버린 것: turbo 형태(코트 밑단 너덜), 3면도 투영 정점 색(가려진 곳 35%가 번짐), Paint turbo 1024, A안(전신 Paint만 고해상도 — 얼굴 여전히 흐림), octree 512(8GB에서 VRAM 부족).

### 생성 도구 (저장소 밖: `gguhansung/assets/castle/statues/`) — **아직 버전 관리 안 됨**

| 파일 | 하는 일 |
|---|---|
| `setup.sh` | `~/tools/Hunyuan3D-2` + Python 3.10 venv + torch cu124. transformers 4.48.3·diffusers 0.32.2 고정(최신은 체크포인트를 못 읽음) |
| `setup_paint.sh` | micromamba로 `~/tools/cuda-build`에 nvcc 12.4 + gcc 12(Ubuntu 26.04 apt에 없음) → Paint 렌더러 2개 빌드 |
| `prep_views.py` | 3면도 시트 → 정면·왼쪽·후면 정사각 그림. 자동 분할이 틀리는 시트는 `MANUAL_X`(난워니·야뿌·옥독·윤타미) |
| `generate.py` | 형태 생성 (`--octree`, `--faces`, `--turbo`) |
| `paint.py` | 전신 텍스처. `make_pipeline()`이 8GB용 설정을 모은다(아래 함정) |
| `head_paint.py` | B안 머리 텍스처 + 몸과 합치기. `face_crops.json`(시트별 얼굴 클로즈업 영역)을 읽는다. `--refs-only`로 참고 그림만 |
| `colorize.py` | 3면도 투영 정점 색 (버린 방식, 비교용) |
| `snapshot.py` | GPU 없이 GLB 4방향 회색 렌더 |
| `viewer/index.html` | 석상 단독 뷰어. `python -m http.server 5180` 후 `/viewer/?m=꾸티뉴&cmp=face` 등. 비교 모드 `cmp=1·color·hd·face`, 물들이기 슬라이더 |
| `sheets/`·`photos/` | 3면도.zip·꾸한성 사진 파일.zip을 푼 원본 (맥 NFD 파일명을 NFC로 고침) |
| `views/`·`head_refs/` | 잘린 입력 그림 / 머리 참고 그림(`head_refs/_all.png`에 한 장으로) |
| `out/`·`out_hd/` | 결과 GLB. 최종은 `out/{이름}_face_paint.glb` |

순서: `setup.sh` → `setup_paint.sh` → `prep_views.py sheets views` → `generate.py views out_hd … --octree 380 --faces 100000` → `paint.py views out_hd out_hd … --res 2048 --full` → `head_paint.py … --full`.

### 8GB에서 Paint를 돌리려고 넣은 우회 (paint.py) — 지우지 말 것

1. `HF_HUB_DISABLE_XET=1`, 다운로드 타임아웃 60초 — 기본 `hf_xet` 다운로드가 0바이트에서 응답 없이 멈춘다.
2. Paint UNet은 fp32 `diffusion_pytorch_model.bin`(6.8GB)만 읽는다. 같은 폴더의 `.safetensors`는 이미지 어댑터 키가 더 있는 다른 버전이라 쓸 수 없다 → `.safetensors`는 받지 않는다.
3. 설정 `device = "cpu"` — 기본(cuda)이면 offload를 켜기 전에 두 확산 모델이 한꺼번에 GPU로 올라가 6.7GB에서 OOM.
4. full Paint는 UNet 안의 텍스트 임베딩을 쓰는데 offload 중엔 CPU에 남는다 → `encode_prompt`에서 실행 장치로 옮겨 넘긴다.
5. 얼굴 클로즈업 배경 제거는 `isnet-anime` (기본 u2net은 머리카락·얼굴 절반을 지운다).

1. **사용자 화면 확인**: 석상 둘러보기(F)·3인칭 드래그 회전(B1 좁은 복도에서 카메라가 벽에 붙는 느낌 포함), 모바일 드래그, 물들이기 비율, B안 석상(목·옷깃 이음새, 측면 클로즈업을 좌우로 뒤집어 넣어 한쪽 뺨 무늬가 반대쪽에도 생겼는지).
2. **멤버 ↔ 시트 매핑 확정**: 3면도 11장 중 mock 멤버와 맞는 건 7명(꾸티뉴·난워니·다뮤·옥독·윤타미·모야·야무지). 만조·만조2·야뿌·하루노츠키는 mock에 없고, 운영 멤버 명단과 대조 안 함. 만조2(격자 선화)는 만조와 같은 캐릭터로 보고 얼굴만 만조 컬러 클로즈업을 썼다 — 몸 텍스처에 격자선이 나올 수 있다. 하나만 남길지 정할 것.

5. **물들이기 비율** `STONE_TINT` 확정 (뷰어 슬라이더로 고르기). 텍스처 석상을 쓰면 돌 색은 임시 도형·실패 시에만 쓰인다.
