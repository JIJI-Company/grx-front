## 1. 충돌 처리

- 현재: `floors.ts`의 `walk` 직사각형만 검사. 석상·기둥 통과됨. `movement.ts`는 축별 검사로 벽 미끄러짐 처리.
- 할 것
  - `FloorDef`에 `blockers`(원·박스) 추가: 기둥, 난간, 해치 테두리
  - 석상은 배치 좌표 + scale 비례 반지름으로 자동 등록
  - `isWalkable` = 걷기 영역 안 && 막힌 곳 아님. 미끄러짐 로직 유지
  - 유저끼리는 충돌 없음 (겹쳐 갇히는 문제 방지)
- 파일: `castle/floors.ts`, `castle/movement.ts`, 테스트

## 2. 석상 클릭 소리

- 현재: 석상은 클릭을 받지 않음. E 키로 정보 창만 열림.
- 할 것: 석상 클릭·탭(raycast) → 소리 재생, 짧은 쿨다운. 클릭 자체가 사용자 조작이라 브라우저 자동재생 제한에 걸리지 않음
- 이때 `castle/sound.ts` 기본 구조(로딩·재생·음소거)를 같이 만든다 → 8번이 재사용
- 파일: `Statue.tsx`, `castle/sound.ts`, `public/castle/sfx/*`

## 3. 조명·후처리

- 현재: Bloom(threshold 0.85, intensity 0.7) + Vignette만 (`CastleCanvas.tsx`). 등롱은 빛나 보이기만 하고 주변을 비추지 않음
- 할 것
  - 등롱 단계(1/5/20/50)별 석상 발광·광원 반경·바닥 빛 번짐 차등
  - 석상당 광원 1개 + 바닥 빛 데칼 (실제 광원 남발 금지)
  - ACES 톤 매핑 + 층별 색감: B1 따뜻한 주황 / B2 탁한 금색 / B3 차가운 붉은색
  - B3 먼지·불티 파티클, 약한 색수차
  - 저사양 모드: Bloom 해상도↓, 파티클↓ (모바일 자동)
- 파일: `CastleCanvas.tsx`, `Statue.tsx`, `LanternRing.tsx`, `floors/Scene*.tsx`

## 4. B3 거울 바닥

- drei 9.114의 `MeshReflectorMaterial` 사용 (추가 설치 없음)
- 떠 있는 단 바닥과 아래 허공을 반사면으로 → 석상·등롱·유저가 거꾸로 비침
- 반사는 장면을 한 번 더 그려 무거움: 반사 해상도↓ + blur, 저사양·모바일은 광택 바닥으로 대체
- 파일: `floors/SceneB3.tsx`

## 5. 층 이동 연출 + 다다미 열림

## 6. 1인칭/3인칭 전환

- 현재: 카메라가 -z 고정, 회전 없음. 방향키는 화면 기준 (`input.ts`, `FollowCamera.tsx`)

  - 시점 회전: 데스크톱 포인터 락 마우스, 모바일 화면 오른쪽 드래그

## 7. 이모트 + 절 동기화 (백엔드 포함)

- 현재: `protocol.ts`에 emote 자리만 예약, 서버 미구현. 절은 내 화면에서만 보임
- 이모트: 손 흔들기, 앉기 (+ 절을 같은 경로로)
- 프로토콜안: C→S `emote` `{ id }` (ack 없음) / S→C 같은 층 브로드캐스트 `{ sid, id }`. 위치 tick 배치와 별도 이벤트
- 서버: 허용 id 화이트리스트, 1초 1회 제한, 인스턴스 간 전달은 Redis adapter
- 클라이언트: 이동하면 이모트 즉시 취소. 앉기는 다시 움직일 때까지 유지
- 꾸로 GLB에 wave·sit 액션 추가 (Blender, `assets/castle/kkuro.blend`)
- 순서: `api.md`·`security.md` 갱신 → 승인 → 코드
- 파일: 프론트 `protocol.ts`, `session.ts`, `Oni.tsx`, `Hud.tsx`/`LanternPrompt.tsx`, `public/castle/kkuro.glb` / 백엔드 castle gateway·DTO·spec
